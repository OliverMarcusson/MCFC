# Example Catalog

The repository includes small projects that exercise different parts of MCFC.

| Example | Use it for |
| --- | --- |
| [RPC Demo](./rpc-demo.md) | Minimal `mcfd` HTTP request flow |
| [Oracle](./oracle.md) | A richer host-bridge pack using HTTP, time, rand, and player state |
| [Cyber Quotes](./cyber-quotes.md) | Bearer-token HTTP plus text components |
| [Bukkit API Conformance](./bukkit-api-conformance.md) | Vanilla declarations and optional agent callbacks |
| [Debug Function Log](./debug-function-log.md) | Low-level log transport verification |
| [Generated Project](./generated-project.md) | The shape of `mcfc new` output |

Examples are intentionally practical: build them, copy `dist/` into a world, reload, and inspect the generated datapack when something is unclear.
